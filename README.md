# Deep Work

A quiet writing surface over looping ambient video — for flow, reflection, and focus.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scenes

Background clips live in `public/videos/`. Swap files or edit `lib/scenes.ts`:

- **Kelp forest** — Apple Aerial Kelp (`6143116D-03BB-485E-864E-A8CF58ACF6F1`)
- **Cafe** — coffee shop interior (Pexels placeholder)

Draft text and the selected scene persist in `localStorage`.
